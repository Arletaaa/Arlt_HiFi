# Arlt-HiFi v1.0.0

首个可发布版本：本地托管曲库 + 3D CD 货架 + CD 盒详情 + CD 唱片机播放。

- 校验：`Get-FileHash .\arlt-hifi-1.0.0-portable.exe -Algorithm SHA256`。

## 本次内容

- **托管曲库**：导入 `flac` / `wav` / `mp3` / `m4a` / `ogg` 后复制到 `userData/library/<artist>/<album>/<title>.<ext>`，按 `(大小, 时长, 前 256KB SHA-1)` 去重；重命名、设封面、删除只作用于副本。
- **3D CD 货架**：唯一主视图，单排实时货架；拖动限制在 CD 列表内，越界阻尼回弹；搜索直接飞到目标 CD。
- **CD 盒详情**：透明宝石盒开盖、盘片拖出、合盒返回。
- **唱片机**：盘片吸附、Start/Stop 起转、唱臂拖拽与自动回架、落针播放；转盘、唱臂、状态灯映射真实播放与电机状态。
- **详情播放条**：进度拖动 / 点击 / 键盘 seek、上一首 / 播放 / 下一首、顺序 / 循环 / 随机；播放键与唱片机共用同一段逻辑，循环作用于整张 CD。
- **曲库管理**：CD 目录树、拖拽合曲与调序、CD 名与歌名行内编辑、批量合并多首为一张 CD、旧库重扫与目录监听。
- **导入体验**：取消 / 续传、进度反馈与失败原因提示。
- **设置**：材质预设（台面 / 台底 / 墙面）、四档光效、音量环、曲库入口。
- **署名**：CD 盒与唱片机模型为 CC-BY 4.0，署名在设置浮层底部。
