# Arlt-HiFi v1.0.0

首个可发布版本：本地托管曲库 + 3D CD 货架 + CD 盒详情 + CD 唱片机播放。

## 下载

| 文件 | 大小 | SHA-256 |
| --- | --- | --- |
| `arlt-hifi-1.0.0-setup.exe` | 98.01 MiB（102,772,286 B） | `e3f00f37677aa8cc718b3e605b97203706c075b05a4026c18068c590237f0dff` |

Windows x64 安装包（NSIS）。双击进入安装向导：可改安装目录、创建开始菜单与桌面快捷方式、带卸载项；不做静默强制安装。

- 未签名：SmartScreen 会提示"未知发布者"，选择"更多信息 → 仍要运行"。
- 校验：`Get-FileHash .\arlt-hifi-1.0.0-setup.exe -Algorithm SHA256`。

## 安装后

- 程序默认装在当前用户目录（安装向导里可改到 D 盘等位置）。
- 数据固定写到 `%APPDATA%\Arlt-HiFi`：`settings.json`、`library.json`、`covers/` 与 `library/`。
- **导入的音乐会被复制进 `library/`**，所以 C 盘占用约等于导入音频总量；卸载时默认保留这些数据，需要清空请手动删除该目录。
- 卸载入口：Windows 设置 → 应用 → Arlt-HiFi，或开始菜单里的卸载快捷方式。

## 本次内容

- **托管曲库**：导入 `flac` / `wav` / `mp3` / `m4a` / `ogg` 后复制到 `userData/library/<artist>/<album>/<title>.<ext>`，按 `(大小, 时长, 前 256KB SHA-1)` 去重；重命名、设封面、删除只作用于副本。
- **3D CD 货架**：唯一主视图，单排实时货架；拖动限制在 CD 列表内，越界阻尼回弹；搜索直接飞到目标 CD。
- **CD 盒详情**：透明宝石盒开盖、盘片拖出、合盒返回。
- **唱片机**：盘片吸附、Start/Stop 起转、唱臂拖拽与自动回架、落针播放；转盘、唱臂、状态灯映射真实播放与电机状态。
- **详情播放条**：进度拖动 / 点击 / 键盘 seek、上一首 / 播放 / 下一首、顺序 / 循环 / 随机；播放键与唱片机共用同一段逻辑，循环作用于整张 CD。
- **曲库管理**：CD 目录树、拖拽合曲与调序、CD 名与歌名行内编辑、批量合并多首为一张 CD、旧库重扫与目录监听。
- **导入体验**：取消 / 续传、进度反馈与失败原因提示。
- **设置**：材质预设（台面 / 台底 / 墙面）、四档光效、音量环、曲库入口。
- **署名**：CD 盒与唱片机模型为 CC-BY 4.0，署名在设置浮层底部。

## 已知限制

- 安装包与主程序均未做代码签名。
- 装包版完整交互（导入 → 播放 → 开盒 → 拖盘上机 → 落针 → 播放模式 → 重启恢复）仍待真机手测；本版本只做了包内容、版本信息与哈希校验。
- 曲库数据位置暂不可配置（固定在 `%APPDATA%`）；需要放 D 盘可先用目录联接：`mklink /J "%APPDATA%\Arlt-HiFi\library" "D:\Arlt-HiFi-library"`（需在首次导入前建立）。
- 列表视图、无 WebGL / 低帧率降级不在 v1.0 范围内。
- 标签写回、拆文件与性能收口留待后续版本。
