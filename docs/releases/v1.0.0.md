## 在线演示

[arletaaa.github.io/Arlt_Hifi](https://arletaaa.github.io/Arlt_Hifi/)（推送 `main` 后由 GitHub Actions 部署）。演示站是渲染层静态包 + 示例曲库，可体验 3D 货架、搜索、开盒与唱片机；导入曲库、真实音频播放与设置持久化只在桌面安装版可用。

## 安装后

- 安装向导里可以分别选择**软件安装位置**与**曲库位置**；两者都会在你选择的路径下新建文件夹（`Arlt-HiFi` 与 `Arlt-HiFi Library`），页面上实时显示最终路径，不会把文件直接铺在你选的目录里。
- 曲库默认与软件目录同级（例如 `D:\Apps\Arlt-HiFi Library`），可改到任意盘；安装器创建该目录并把选择结果写进 `install.ini`，应用启动时读取。
- **导入的音乐会被复制进曲库目录**；卸载只删除软件目录，曲库、`settings.json`、`library.json` 与封面都保留，需要清空请手动删除。
- 卸载入口：Windows 设置 → 应用 → Arlt-HiFi，或开始菜单里的卸载快捷方式。

## 本次内容

- **托管曲库**：导入 `flac` / `wav` / `mp3` / `m4a` / `ogg` 后复制到 `userData/library/<artist>/<album>/<title>.<ext>`，按 `(大小, 时长, 前 256KB SHA-1)` 去重；重命名、设封面、删除只作用于副本。
- **3D CD 货架**：唯一主视图，单排实时货架；拖动限制在 CD 列表内，越界阻尼回弹；搜索直接飞到目标 CD。
- **CD 盒详情**：透明宝石盒开盖、盘片拖出、合盒返回。
- **唱片机**：盘片吸附、Start/Stop 起转、唱臂拖拽与自动回架、落针播放；转盘、唱臂、状态灯映射真实播放与电机状态。
- **详情播放条**：进度拖动 / 点击 / 键盘 seek、上一首 / 播放 / 下一首、顺序 / 循环 / 随机；播放键与唱片机共用同一段逻辑，循环作用于整张 CD。
- **曲库管理**：CD 目录树、拖拽合曲与调序、CD 名与歌名行内编辑、批量合并多首为一张 CD、旧库重扫与目录监听。
- **导入体验**：取消 / 续传、进度反馈与失败原因提示。
- **设置**：材质预设（台面 / 台底 / 墙面）、四档光效、音量环、曲库入口。
- **署名**：CD 盒与唱片机模型为 CC-BY 4.0，署名在设置浮层底部。

## 已知限制

- 安装包与主程序均未做代码签名。
- 装包版完整交互（导入 → 播放 → 开盒 → 拖盘上机 → 落针 → 播放模式 → 重启恢复）仍待真机手测；本版本只做了包内容、版本信息与哈希校验。
- 曲库位置只在安装时选择；安装后如需更换，需要重新安装并手动迁移旧曲库（`library.json` 里是绝对路径）。
- 列表视图、无 WebGL / 低帧率降级不在 v1.0 范围内。
- 标签写回、拆文件与性能收口留待后续版本。
