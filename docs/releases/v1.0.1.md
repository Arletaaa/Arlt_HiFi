## 本次修复

- 读取 `library.json` 时**保留**其它曲库目录下的条目；只在曲库展示与媒体协议白名单里按当前曲库目录过滤。
- 因此：换库目录后旧条目只是不显示，不会再被写掉；把曲库目录切回原位置，或把文件迁过去，记录仍在。
- 曲库位置仍只能在安装时选择；设置 → 音乐库 会显示当前目录与来源（安装器配置 / 默认位置）。

## 升级说明

直接安装覆盖即可，`%APPDATA%\Arlt-HiFi` 下的清单与设置会保留。

## 已知限制

- 安装包与主程序均未签名。
- 曲库目录在安装时选择，安装后暂不支持在应用内更改。
- 换过曲库目录后，旧目录里的音频不会被删除或迁移，只是不再出现在曲库中。
- 安装到盘符根目录或受策略保护的位置可能失败，建议用 `H:\Apps` 这类子目录。
