## 本次变更

- 设置 → 音乐库 新增「更改曲库位置」：用系统目录选择器切换曲库根目录，写入 `settings.json` 的 `libraryRoot`；设置页显示当前路径与来源（应用内设置 / 安装配置 / 默认位置）。
- 目录解析优先级：`settings.libraryRoot` > 安装器 `install.ini`（userData → 安装目录）> 默认 `%APPDATA%\Arlt-HiFi\library`。安装页继续保留，但只作为首次默认值。
- 切换**只改根目录、不迁移文件**；旧目录的清单条目保留，只是不再显示，切回原目录即可恢复。
- 目标目录已有音频文件时先弹窗警告；从曲库目录内部导入会被拦截并提示，不再生成 ` (2)` 副本。
- 删除曲目改为 `shell.trashItem()`，文件进系统回收站；回收站不可用时才报错。

## 升级说明

直接安装覆盖即可，`%APPDATA%\Arlt-HiFi` 下的清单与设置会保留。如果之前用安装向导选过曲库目录，升级后仍按 `install.ini` 生效；只有在应用内切换过曲库位置，才会写 `settings.json` 并优先于安装配置。

## 已知限制

- 安装包与主程序均未签名。
- 切换曲库位置不迁移旧文件；旧目录的条目不再显示，需要空间请手动清理。
- `settings.json`、`library.json` 与封面缓存仍固定在 `%APPDATA%\Arlt-HiFi`。
- 安装到盘符根目录或受策略保护的位置可能失败，建议用 `H:\Apps` 这类子目录。
