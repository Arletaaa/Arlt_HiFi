# Arlt-HiFi v1.0.3

修复曲库切换后的导入、重扫与跨库重复判定，并重排设置页的音乐库区域。

## 本次修复

- 切换曲库只允许「没有音频文件的目录」或「已登记的曲库」：普通音乐文件夹会被拒绝并重新选择，不再切过去看到空曲库；之前用过的曲库目录可以直接切回。
- 重扫、重命名、编辑、批量改 CD、设封面、删除只作用于当前曲库：重扫不会再短暂带出其它目录（例如 Roaming）的曲目，也不会改写旧目录的记录。
- 失效条目的清理只针对当前曲库，旧曲库目录不再被后台读取。
- 跨曲库导入不再误判重复：去重只看当前曲库内的条目，切到新曲库后可以重新导入旧曲库中已有的歌曲；同一曲库内的重复仍会跳过。

## 设置页

- 音乐库区域重排为「导入 / 管理 / 曲库位置」三块：导入使用主次按钮，管理改为次级按钮，曲库位置独立到底部并弱化，路径与来源（应用内设置 / 安装配置 / 默认位置）分开展示。

## 升级说明

直接安装覆盖即可，`%APPDATA%\Arlt-HiFi` 下的清单与设置会保留。切换曲库仍然不迁移文件：旧目录的曲目只是不再显示，清单记录保留，切回旧目录即可恢复。

## 已知限制

- 安装包与主程序均未签名。
- 仅提供 64 位（x64）安装包；Windows 7 / 8 / 8.1 不受支持（Electron 23 起已移除）。
- `settings.json`、`library.json` 与封面缓存仍固定在 `%APPDATA%\Arlt-HiFi`。
- 安装到盘符根目录或受策略保护的位置可能失败，建议用 `H:\Apps` 这类子目录。
